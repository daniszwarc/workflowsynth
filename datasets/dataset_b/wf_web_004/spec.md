# Workflow: Price-Filtered Product Search

## Context
A shopper wants search results for a product narrowed down to items within their budget.

## Trigger
A search query with a maximum price arrives from the storefront search box.

## Steps
1. Search the product catalog for the query.
2. Filter the search results down to items within the given price range.

## Constraints
- Results above the specified price must never be returned.
